Un document intră cu date personale.

02 · Fluxul de date

Patru pași. Toți în perimetrul tău.

PAS 01 — INGESTIE

Documentele intră prin API, folder sau upload

PDF (inclusiv scanat, cu OCR local), DOCX, e-mail, exporturi CSV/DB. Rulează ca un container Docker on-premise sau în VPC-ul tău.

PAS 02 — DETECȚIE

Modelul NER românesc găsește datele personale

CNP, nume flexionate, adrese, IBAN, telefoane, diagnostice, combinații identificabile — fiecare cu tip, poziție și scor de încredere.

PAS 03 — PSEUDONIMIZARE

Tokeni consistenți, mapare reversibilă doar la tine

Andrei Popescu devine [PERS_01] în tot corpusul. Maparea se stochează într-un vault criptat AES-256, cu chei deținute exclusiv de tine.

PAS 04 — VALIDARE + AUDIT

Un al doilea model încearcă re-identificarea

Primești un scor de risc rezidual per document, zonele incerte merg la revizuire umană, iar fiecare operațiune se scrie într-un jurnal imuabil — dovada ta pentru autoritatea de supraveghere.

03 · Funcționalități

Construit ca infrastructură, nu ca demo.

NER-RO

Motor fine-tuned pentru română

Recall >99% pe CNP și >97% pe nume flexionate. Benchmark publicat, validat pe infrastructură HPC europeană.

VAULT

Pseudonimizare reversibilă

Tokeni stabili cross-document. Re-identificare posibilă doar local, cu cheile tale. Sau ireversibilă, dacă politica o cere.

API

REST + procesare batch

Se integrează în DMS, e-mail sau pipeline-ul tău de date. Foldere întregi procesate cu un singur apel.

RISC

Raport adversarial per document

Nu ne crezi pe cuvânt: un model secund încearcă activ re-identificarea și îți arată exact cât risc a rămas.

AUDIT

Jurnal imuabil + dashboard

Fiecare operațiune, înregistrată. Profiluri de politici pe domenii: juridic, medical, HR. Export pentru DPO.

DEPLOY

On-premise / VPC / air-gapped

Datele tale nu ajung niciodată la noi. Arhitectura poate fi verificată integral de echipa ta de securitate.
